

# Smart Auto Care 🚗

**Smart Vehicle Repair & Maintenance Management System**

## About the Project

Smart Auto Care is a Flutter-based application designed to simplify vehicle maintenance and repair management by connecting vehicle owners, workshops, and drivers through one platform.

## Main User Roles

- **Vehicle Owner:** Manage vehicles, view service history, book workshops, and receive maintenance reminders.
- **Workshop:** Manage service requests, repair jobs, and invoices.
- **Driver:** Handle assigned vehicle tasks and update vehicle or job status.

## Planned Features

- Vehicle profile management
- Digital service history
- Maintenance reminders
- Workshop discovery and booking
- Repair and job status tracking
- Invoice and bill management
- Mileage and GPS-based updates

## Technology Stack

- Flutter
- Dart
- Firebase
- GitHub Actions
