# Smart Auto Care

**Smart Vehicle Repair & Maintenance Management System**

## About the Project

Smart Auto Care is a vehicle maintenance and repair management system connecting vehicle owners, workshops, and drivers through one platform.

The system consists of a Flutter mobile application and a Python-based web application and backend.

## Main User Roles

- **Vehicle Owner:** Manage vehicles, view service history, book workshops, and receive maintenance reminders.
- **Workshop:** Manage service requests, repair jobs, and invoices.
- **Driver:** Handle assigned vehicle tasks and update vehicle or job status.
- **Administrator:** Manage users, workshops, and platform operations.

## Planned Features

- Vehicle profile management
- Digital service history
- Maintenance reminders
- Workshop discovery and booking
- Repair and job status tracking
- Invoice and bill management
- Mileage and GPS-based updates
- Workshop management dashboard
- Administrative dashboard

## Technology Stack

| Component | Technology |
|---|---|
| Mobile Application | Flutter and Dart |
| Web Application | Python and Django |
| Backend API | Django REST Framework |
| Database | PostgreSQL (planned) |
| Version Control | Git and GitHub |
| CI/CD | GitHub Actions |

Firebase is not part of the planned architecture.

## Repository Structure

- `mobile_app/` - Flutter mobile application
- `backend/` - Django backend and REST API
- `web/` - Workshop and admin website
- `database/` - Database documentation and migrations
- `docs/` - Project documentation
